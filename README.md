# Biblioteca Digital UniFECAF — 

Projeto acadêmico demonstrativo desenvolvido com HTML5 e CSS3 para a disciplina Design Web.

## Como abrir
1. Extraia a pasta `biblioteca-unifecaf-personalizada`.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server, se estiver instalada).

## Estrutura
- `index.html`: estrutura e conteúdo da página.
- `css/style.css`: cores, layout, tipografia, responsividade e estados de foco.
- `assets/imagens/`: imagens locais utilizadas na página.

## Importante
- Os títulos de livros e ambientes são exemplos ilustrativos, não um catálogo ou lista oficial de unidades da UniFECAF.
- O projeto é uma interface estática em HTML e CSS. Não possui sistema real de pesquisa, login, empréstimo ou integração com catálogo.
- Revise e compreenda o código, teste em desktop e celular e escreva o relatório com base no que você verificar e aprender.
- As imagens foram mantidas do ZIP de referência enviado pelo usuário.


Imagem de referência visual: `assets/imagens/referencia-visual.png`. As imagens ilustrativas foram atualizadas para diferenciar esta versão do projeto. Os títulos e conteúdos exibidos são demonstrativos, não um catálogo oficial.

Biblioteca Digital UniFECAF

Projeto acadêmico desenvolvido para a disciplina Design Web, com o objetivo de criar uma interface de biblioteca digital utilizando HTML5 e CSS3.

Objetivo do projeto

Desenvolver uma página web moderna, intuitiva e responsiva, que facilite a exploração de conteúdos acadêmicos e incentive os estudantes a conhecer diferentes áreas do conhecimento.

Como executar

Baixe ou clone este repositório.

Abra a pasta do projeto no Visual Studio Code.

Abra o arquivo index.html diretamente no navegador.

Para facilitar o desenvolvimento, você também pode utilizar a extensão Live Server no VS Code, caso esteja instalada.

Estrutura do projeto

index.html: estrutura e conteúdo da página.

css/style.css: estilos, cores, tipografia, layout e responsividade.

assets/imagens/: imagens utilizadas na interface.

README.md: documentação do projeto.

Recursos da interface

Menu de navegação por seções.

Categorias de conhecimento.

Área de destaques com livros ilustrativos.

Seções de apresentação e recursos de estudo.

Layout adaptável a diferentes tamanhos de tela.

Cuidados de acessibilidade, como textos alternativos em imagens e indicação de foco na navegação.

Tecnologias utilizadas

HTML5

CSS3

Git e GitHub para versionamento e publicação.

Observações

Este projeto é uma demonstração acadêmica. Os títulos de livros, conteúdos e ambientes apresentados são ilustrativos e não representam um catálogo oficial da UniFECAF.

A interface não possui funcionalidades de backend, como pesquisa real, login, empréstimos ou integração com um catálogo de livros.

As imagens utilizadas são recursos visuais ilustrativos do projeto.

Publicação

O projeto poderá ser publicado gratuitamente por meio do GitHub Pages após a configuração do repositório.
